# Разбор вопросов без ответа — дизайн

## Цель

Обработать серверную очередь `data/missed_questions.json`: сохранить реальные технические вопросы в `manual_qa`, отфильтровать реплики текущей ветки как болтовню и очистить очередь после разбора.

## Решение

- Использовать существующие ручные ответы для PA, первого слоя, овальных отверстий и PETG Rapid.
- Добавить краткие ответы для засора PETG, подсирания при мультицветной печати и неплотной крышки камеры. Для засора и очистки использовать только проверенные URL Anycubic; для крышки — текст без неподтверждённой ссылки.
- Добавить узкую эвристику для сообщений-реплик и обсуждения питания/прогрева/личного опыта из текущей ветки. Явные просьбы о помощи и подробный технический вопрос не фильтровать.
- После проверки записать локальную и серверную очередь как `[]`, не затрагивая посторонний неотслеживаемый скрипт.

## Проверка

Добавить позитивные и негативные тесты эвристики, проверить ручной матчинг новых ключей, затем выполнить полный набор pytest и проверить `git diff`/содержимое очереди.
